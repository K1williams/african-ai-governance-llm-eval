# 12-item source-traceable model-evaluation feasibility pilot

This is the narrow, executable experimental companion to the main 60-item study. Its output is **raw observed behavior**, not accuracy assessed by independent domain experts.

- 12 curated questions: three countries × {one factual retrieval, one proposal-status question, one false premise, one future/beyond-document question}.
- Audited against dated Rwanda 2023 policy **summary** (WHO-hosted official document copy), Kenya March 2025 AI strategy, Nigeria September 2025 AI strategy. See [SOURCE_AUDIT.md](SOURCE_AUDIT.md).
- Two conditions: `closed` (no policy facts supplied) versus `context` (a concise, source-checked *paraphrase* provided with the same question). **Do not call this PDF excerpt retrieval or RAG.**
- Pre-specified, deterministic random order (seed 2026) with greedy decoding and complete model/revision metadata.
- Open-weight baseline: Qwen2.5-0.5B-Instruct (small baseline, not a frontier model). Run in GitHub Actions on CPU without provider API keys.
- Raw observations and readable side-by-side results are generated by code; accuracy must be assessed separately, without using the tested model as its own judge.

## Execute

```bash
python -m unittest discover -s pilot -v
python -m pilot.offline_eval --dry-run
# To perform actual inference, install compatible torch CPU / transformers 4.46.3 and provide model-download internet access:
python -m pilot.offline_eval --model Qwen/Qwen2.5-0.5B-Instruct --max-items 12
```

The workflow [experimental-open-model-pilot.yml](../.github/workflows/experimental-open-model-pilot.yml) runs after the pipeline files change, writes a GitHub Actions artifact and commits raw outputs back to the repository **only after completion**. It consumes public GitHub Actions compute and downloads public model weights. If CI fails, there are no model responses and no model claims.

**What this can establish:** whether this *specific* 0.5B model produced certain responses with and without short vetted factual contexts on these 12 selected questions. **What it cannot:** establish broad LLM reliability, statistically robust accuracy improvements, regulatory status in 2026, or reproducibility of other models.
